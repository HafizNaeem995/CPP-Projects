# STUDENT FEE MANAGEMENT SYSTEM
**Programming Language:** C++  
**Project Type:** Console-Based Application

## 1. Problem Statement
Educational institutions need an efficient way to manage student fee records, calculate scholarships, track payments, and identify outstanding dues. The system should automate these calculations and generate individual student fee reports.

## 2. INPUT REQUIREMENTS

The system must accept the following information from the user:

### A. Student Information
1. Student Name
2. Registration Number
3. Department
4. Semester

### B. Fee Information
5. Total Semester Fee (Rs.)
6. Scholarship Percentage (%)

### C. Payment Information
7. Amount Already Paid (Rs.)

## 3. PROCESSING REQUIREMENTS

The system must perform the following calculations:

1. **Scholarship Amount**
   - Calculate the scholarship using the total semester fee and scholarship percentage.

2. **Final Payable Fee**
   - Subtract the scholarship amount from the total semester fee.

3. **Remaining Dues**
   - Subtract the amount already paid from the final payable fee.

4. **Payment Status**
   - If remaining dues = 0: FULLY PAID.
   - If remaining dues > 0: PARTIALLY PAID.
   - If amount paid = 0: UNPAID.
   - If amount paid exceeds payable fee: Display an appropriate error.

## 4. OUTPUT REQUIREMENTS

The system must display a complete student fee report containing:

- Student Name
- Registration Number
- Department
- Semester
- Total Semester Fee
- Scholarship Percentage
- Scholarship Amount
- Final Payable Fee
- Amount Already Paid
- Remaining Dues
- Payment Status

## 6. ADDITIONAL REQUIREMENTS

- The system should support multiple student records.
- Reject negative fee amounts.
- Scholarship percentage must be between 0 and 100.
- Payment amount must not exceed the final payable fee.
- Provide an option to calculate another student's fee.
- Provide an option to exit the program.
